# 🌐 Personal Homepage Project

**HTML & CSS — Multi‑Section Website**

## 📄 Project Overview

This project is a personal homepage created using semantic HTML5 and custom CSS. It includes a header, navigation menu, multiple content sections, and a featured projects table. The purpose of this assignment is to demonstrate foundational web design skills, including layout, styling, navigation structure, and responsive design principles.

The page introduces the author, showcases sample projects, and provides a clean, organized structure suitable for a beginner‑level portfolio site.

## 🎨 Features

- **Semantic HTML Structure:**
  - Organized layout using `<header>`, `<nav>`, `<main>`, `<section>`, and `<footer>`.
  - Clean separation of content and presentation.

- **Navigation Menu:**
  - Horizontal navigation bar.
  - Smooth hover transitions.
  - Internal links to page sections.

- **About Section:**
  - Personal introduction.
  - Overview of learning goals and project purpose.

- **Projects Section:**
  - Styled table with:
    - Caption.
    - Column highlighting.
    - Sample project entries.
    - Placeholder images.
    - Demonstrates `<table>`, `<colgroup>`, and semantic formatting.

- **Styling (styles.css):**
  - Gradient background.
  - Flexbox navigation.
  - Hover scaling effects on sections.
  - Box shadows and borders for visual depth.
  - Consistent color palette.

## 🚀 GitHub Pages Hosting

This project is hosted using GitHub Pages.

### GitHub Pages Setup

1. Open the repository on GitHub.
2. Go to **Settings** → **Pages**.
3. Under **Branch**, select:
   - `main`
   - `/ (root)`
4. Save the settings.
